## Reporting a Vulnerability

We take the security of **Aegis Code** very seriously. If you discover a security vulnerability within this engine:

1. **Do NOT** open a public GitHub issue.
2. Please report security issues privately by submitting a detailed advisory or contacting the maintainer via GitHub profile.
3. Include details about the vulnerability, potential impact, and steps to reproduce.

We will acknowledge your report within **48 hours** and work on a fix as quickly as possible.
