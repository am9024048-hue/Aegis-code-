# Contributing to Aegis Code 🛡️

Thank you for your interest in contributing to **Aegis Code**! We welcome contributions from developers, security researchers, and open-source enthusiasts.

---

## 🚀 How to Contribute

### 1. Reporting Bugs & Vulnerabilities
- Check existing issues before opening a new one.
- Provide detailed steps to reproduce the issue along with environment details.

### 2. Suggesting Features
- Open an issue describing the proposed feature and its use case in static analysis/SAST.

### 3. Submitting Pull Requests (PRs)
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/new-rule`
3. Commit your changes: `git commit -m "feat: Add new security pattern for JWT"`
4. Push to your branch: `git push origin feature/new-rule`
5. Create a Pull Request against the `main` branch.

---

## 🎨 Code Style Guidelines
- Follow PEP 8 standards for Python code.
- Ensure all new rules and code patterns are well-documented.
