 Aegis Code
The Next-Generation Security Auditing & Static Code Analysis Engine
إطار عمل ذكي وفائق السرعة لمراجعة الأكواد البرمجية، كشف الثغرات الأمنية تلقائياً، تقييم الدين التقني، وضمان أقصى درجات أمان وسلامة البرمجيات وفق أعلى المعايير العالمية.
📌 نبذة عن الأداة (Executive Overview)
تعتبر أداة Aegis Code درعاً أمنياً متكاملاً للمطورين والشركات، حيث تجمع بين أدوات التحليل الساكن الحديثة (SAST) والتحليل البنيوي للكود. تعمل الأداة محلياً بالكامل لتوفير فحص دقيق وشامل لبيئتك البرمجية قبل عملية النشر (Deployment)، مما يضمن اكتشاف الأخطاء البرمجية والثغرات الأمنية في مراحل التطوير الأولى ومساعدة الفرق البرمجية على بناء تطبيقات متينة وقابلة للتوسع.
⚡ المميزات والقدرات الأساسية (Core Capabilities)
🛡️ الفحص الأمني العميق (Deep SAST Scanning): اكتشاف وتصنيف الثغرات الأمنية وفق المعايير العالمية المعتمدة مثل OWASP Top 10 و CWE (مثل SQL Injection, XSS, Hardcoded Credentials, Buffer Overflow).
📊 تحليل وتقييم الدين التقني (Technical Debt & Metrics): قياس مدى تعقيد الكود (Cyclomatic Complexity)، حساب حجم الدين التقني، وتقديم تقديرات زمنية دقيقة لعمليات إعادة الهيكلة (Refactoring).
🌍 ملاحة وتوثيق ثنائي اللغة (Bilingual Engine AR / EN): إخراج التقارير والتحليلات البرمجية باللغتين العربية والإنجليزية بشكل احترافي لدعم المطورين وفرق العمل المختلفة.
⚡ أمان وخصوصية كاملة (100% Local & Private): معالجة الأكواد البرمجية تتم بالكامل محلياً على بيئتك الخاصة دون الحاجة لإرسال أي بيانات أو أكواد إلى خوادم خارجية.
🚀 دعم متعدد اللغات والمنصات (Multi-Language Support): فحص وتحليل مختلف اللغات البرمجية الشائعة (مثل Python, JavaScript, TypeScript, Go, C/C++) بسرعة فائقة.
📋 تقارير تفصيلية وقابلة للتصدير (Exportable Audit Reports): توليد تقارير شاملة ومصنفة حسب مستويات الخطورة (Critical, High, Medium, Low) بصيغ متعددة مثل JSON و HTML و PDF.
🔄 التكامل مع أدوات التطوير (CI/CD Ready): إمكانية دمج الأداة بسهولة ضمن خطوط إنتاج وتطوير البرمجيات للتحقق التلقائي مع كل Commit أو Pull Request.
🛠️ هيكلية وآلية العمل (Architecture & Workflow)
الالتقاط والتحليل البنيوي: تحليل شجرة الإعراب المجردة (AST Parsing) للكود البرمجي.
مطابقة الأنماط القواعدية: مطابقة الكود مع قاعدة بيانات واسعة من القواعد الأمنية والممارسات البرمجية السليمة.
تقييم الأخطار: تقييم شدة الثغرات وحساب نسبة التعقيد والدين التقني.
توليد التقرير: تقديم تقرير تنفيذي وتقني دقيق باللغة المختارة (عربي / إنجليزي).
💻 التثبيت والاستخدام السريع (Quick Start)
1. استنساخ المستودع (Clone Repository)
git clone https://github.com/am9024048-hue/Aegis-code-.git
cd Aegis-code-
2. تثبيت التبعيات (Install Dependencies)
pip install -r requirements.txt
3. تشغيل الفحص الأمني (Run Audit)
python aegis.py --scan ./your-project-path --lang ar
