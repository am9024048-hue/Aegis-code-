# Changelog 📜

All notable changes to the **Aegis Code** project will be documented in this file.

---

## [1.0.0] - Initial Release

### Added
- **Core Engine**: Advanced static code analysis logic supporting multiple languages (Python, JS, TS, Go, C++, PHP, Java).
- **Security Scanning**: OWASP Top 10 pattern matching for hardcoded secrets, SQL injection, unsafe functions, and weak cryptography.
- **Code Metrics**: Automated calculation for Lines of Code (LOC) and Cyclomatic Complexity score.
- **CLI Interface**: Rich console output with structured summary tables and colored vulnerability banners.
- **Export Engine**: Support for exporting security audit reports in `JSON` format.
- **Documentation**: Professional `README.md`, `LICENSE` (MIT), and repository configuration files.
